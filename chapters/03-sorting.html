3. Sorting

Sắp xếp là thao tác nền. Các thuật toán so sánh tối ưu có độ phức tạp O(n log n) (mergesort, heapsort). Quicksort trung bình O(n log n), xấu nhất O(n²) nếu không randomised tốt.

3.1 Sorting trong C++

vector a = {5,2,8,1,3};
sort(a.begin(), a.end());                 // tăng
sort(a.rbegin(), a.rend());               // giảm
sort(a.begin(), a.end(), greater());

Có thể truyền comparator (lambda hoặc hàm) tùy ý.

3.2 Binary search

Trên mảng đã sắp: O(log n). C++ có binary_search, lower_bound (≥ x), upper_bound (> x).

Kỹ thuật binary search trên đáp án cũng rất mạnh khi tính chất đơn điệu.
