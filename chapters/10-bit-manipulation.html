10. Bit manipulation

Thao tác trên biểu diễn nhị phân rất nhanh.

  • Phép: & | ^ ~ << >>.
  • Biểu diễn tập hợp bằng bitmask khi n ≤ 20–25.
  • Tối ưu DP trên tập con (SOS DP, enumeration of subsets…).
if (x & (1 << k)) { /* bit k bật */ }
x |= (1 << k);   // bật
x &= ~(1 << k);  // tắt
x ^= (1 << k);   // đảo
int b = x & -x;  // bit thấp nhất đang bật
