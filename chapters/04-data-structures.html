4. Data structures

Chọn đúng cấu trúc dữ liệu thường quyết định độ phức tạp.

  • vector: mảng động, push_back O(1) amortized, truy cập O(1).
  • set / multiset: cây cân bằng, thêm/xóa/tìm O(log n), luôn có thứ tự.
  • map / unordered_map: key→value. map O(log n) có thứ tự, unordered_map trung bình O(1).
  • queue, stack, deque: đầu/cuối O(1).
  • priority_queue: heap, lấy max/min O(log n).
  • bitset: mảng bit tối ưu.

Iterator và range cho phép dùng thuật toán chuẩn (sort, lower_bound, accumulate…). So với chỉ mảng + sort, cấu trúc động giúp xử lý cập nhật xen kẽ truy vấn hiệu quả hơn.
