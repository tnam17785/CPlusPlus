1. Introduction

Competitive programming kết hợp hai kỹ năng: thiết kế thuật toán (tìm cách giải đúng và đủ nhanh) và cài đặt thuật toán (viết code chính xác, gọn, chạy kịp thời gian).

Khác phần mềm thông thường, chương trình thi đấu thường ngắn, viết nhanh, không cần bảo trì lâu dài, nhưng phải đúng ngay từ lần nộp đầu tiên vì hệ thống chấm bằng test case.

1.1 Ngôn ngữ lập trình

Ba ngôn ngữ phổ biến nhất là C++, Python và Java. C++ chiếm ưu thế tuyệt đối nhờ tốc độ và STL mạnh. Python tiện khi cần số nguyên lớn sẵn. Java cũng ổn định. Hầu hết ví dụ trên trang này dùng C++.

1.2 Template C++ tiêu chuẩn

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);
    // giải bài ở đây
    return 0;
}

bits/stdc++.h kéo gần như toàn bộ thư viện chuẩn (GCC). Hai dòng sync giúp tăng tốc nhập xuất. Biên dịch khuyến nghị: g++ -std=c++17 -O2 -Wall sol.cpp -o sol.

1.3 Nhập xuất

Dùng standard streams (cin/cout hoặc scanf/printf). Đọc cả dòng có khoảng trắng bằng getline. Khi bài yêu cầu file có thể freopen.

1.4 Làm việc với số

int (32-bit) khoảng ±2·10⁹. long long (64-bit) khoảng ±9·10¹⁸ — dùng khi cần số lớn. Lưu ý: nhân hai int vẫn ra int, phải ép kiểu sớm.

Modular arithmetic: nhiều bài yêu cầu kết quả modulo 10⁹+7. Có thể lấy dư trước rồi mới cộng/trừ/nhân. Số thực dùng double/long double; so sánh bằng epsilon (thường 1e-9) thay vì ==.

1.5 Rút gọn code

Dùng using ll = long long;, using vi = vector<int>; và macro cẩn thận (có ngoặc) để viết nhanh hơn trong giờ thi.

1.6 Toán học nền & tài nguyên

Cần nắm tổng cấp số cộng/nhân, tổng 1..n, tổng bình phương, ước lượng tổng điều hòa, Fibonacci, logarit, tập hợp, logic. Các cuộc thi chính: IOI, ICPC, Codeforces, AtCoder. Tài liệu thêm: CSES, CLRS, Algorithm Design.
